# whaleshell documentation

whaleshell runs coding agents inside policy-bound containers. A compute
**provider** (Docker or Podman) hosts the sandbox and egress sidecar; an
optional gateway stores secrets and composes provider profiles.

> You need a working container engine before creating a sandbox.
